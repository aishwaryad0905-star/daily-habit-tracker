Daily Habit Tracker

A simple and user-friendly web application to manage and track daily habits.

Features

- Add new habits
- Mark habits as completed
- Delete habits
- Track daily progress
- View progress percentage with a progress bar

Technologies Used

- HTML
- CSS
- JavaScript

Objective

The main objective of this project is to encourage consistency and productivity by helping users track their daily habits.

Learning Outcomes

- HTML page structure
- CSS styling
- JavaScript DOM manipulation
- Event handling
- Dynamic progress calculation
